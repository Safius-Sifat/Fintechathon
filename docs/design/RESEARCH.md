## What this changes in DIRECTION.md

1. **Home is a wallet.** Account chip, hero numeral, Send / Receive / Scan, token list. The agent is a section on it, not the page.
2. **The seal stays, but narrower.** It is now (a) the budget gauge on the agent card and agent detail (Revolut shows a circular spent-against-limit gauge; this is the same job), (b) the signature on approval, (c) the icon and Welcome.
3. **One new tab: Agents.** The plan's agent screens (Approvals, Task, Control, Schedule) need a home; Home keeps one agent strip and a pending-request row. This is a decision for the user.
4. **Honest wallet adaptation:** no fiat column, no chart, no total value. The hero is the DemoUSD balance with "Test funds. No market value." Review shows the token amount and the ETH fee as separate rows, never summed.
5. **Token glyphs are monochrome discs** (ink on raised ground) so four coloured logos do not become the confetti the current app already has.

**My calls (no screen backed them):**
- **Passphrase.** No search was run; the plan requires an optional passphrase with its own acknowledgement ("words alone may restore a different valid address"). It is designed from the plan's text only.
- **Remove wallet is not red.** All four references use a red destructive button. The accent here is a red that means "signed by you", so a second red meaning "danger" would blur both. The button is ink and says exactly what it does.
- **No Copy on the recovery phrase.** Four products offer it. The plan forbids a secret on the clipboard, so the phrase screen has none.
- **Status steps on transaction detail** (Submitted, Included, Finalized) follow the plan's lifecycle; the references show one status word.
- **RPC status and the testnet funding guide** have no search result: they follow the plan's Network/Help line.
